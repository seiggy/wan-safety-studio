# Triage labels

Use this mapping whenever a skill names a triage role.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | A maintainer needs to evaluate the issue. |
| needs-info | needs-info | Waiting for information from the reporter. |
| ready-for-agent | ready-for-agent | Specified well enough for an unattended agent. |
| ready-for-human | ready-for-human | Needs a person to implement it. |
| wontfix | wontfix | Will not be worked on. |

Edit the GitHub label column if the team's names change.
